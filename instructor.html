Keeping the room even

  • Every lab ends with an amber Finished early? Stretch tasks box (two tasks, with hints). Point fast pairs there rather than letting them start the next lab, so the class stays on the same slide.
  • ECE experiments (ECE 1 UART frames, ECE 2 sampling and aliasing, ECE 3 FIR vs IIR filters) are for fast pairs and for home. ECE 2 makes a good 3-minute live demo after Lab 3: set F_SIGNAL to 900 Hz and ask the class to predict what 1000 samples per second will show.
  • Labs 2, 3, 4 and ECE 1 include Wokwi's logic analyzer. Install PulseView on the projector laptop (sigrok.org, free) and show one capture: switch bounce in Lab 2, or the I²C address 0x3C and ACK in Lab 4. Test it the day before.
  • Labs 7 (deep sleep) and 8 (live weather from a web API) are take-home. Mention them on the roadmap slide (51) and in the handout checklist. They are not part of the grade.

End of day: grades and certificates (printed on the spot)

  1. Open the Google Sheet → Workshop → Build / update gradebook.
  2. Enter Challenge /13 (from your paper scores) and Participation /5; correct Labs /6 using lab5_devices.csv where needed.
  3. Download the Gradebook as CSV, open certificates.html, load the CSV and press Print all certificates (A4, Landscape, Margins: None, Background graphics on).
  4. Sign and hand out. Allow about 10 minutes for printing 60 certificates: ask NAVKIS to keep a printer with enough A4 sheets (or certificate stock) ready near the lab.

If something goes wrong

ProblemFix
Wokwi slowThe labs use MicroPython, which starts without the build queue. If a student pastes the Arduino C version by mistake it will queue: send them back to the MicroPython steps on the lab page.
ImportError: no module named ssd1306 (Lab 4)The second file is missing: ▾ next to the tabs → New file → ssd1306.py, paste the driver from the lab page.
Dashboard shows “Offline”The dashboard listens to all three public brokers at once, and each student device uses the first broker that answers, so nothing needs changing. If the college firewall blocks WebSockets, use your phone hotspot for the projector laptop. Students' ESP32s still work, because they connect through Wokwi's cloud.
No devices appearCheck the topic root in the sketch (navkis/ews2026) matches config.js. Ask one student to read their Serial Monitor aloud.
Internet down completelySlides work offline from the ZIP. Do the labs as a projector walkthrough, and give the site link for practice at home.
